# HF ZeroGPU build contract: on a `sdk: gradio` Space, Hugging Face's install
# layer itself runs
#   pip install -r requirements.txt gradio[oauth,mcp]==<hub default> torch<=<hub cap> uvicorn websockets spaces
# so NEVER add `gradio` here and never upper-bound `torch`: a second, narrower
# constraint makes the whole install unresolvable (ResolutionImpossible ->
# BUILD_ERROR). `gradio`, `uvicorn`, `websockets` and `spaces` (the ZeroGPU
# runtime) are all provided by that layer; app.py detects `spaces` at import
# time and falls back to plain CPU execution when it is absent (local dev).
# =============================================================================
